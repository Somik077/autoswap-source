## Сборка

- 1.21.11 и 1.21.4: Loom `fabric-loom`, yarn-маппинги, Java 21, `./gradlew build`.
  Запускать с `JAVA_HOME="C:/Program Files/Java/jdk-21"`.
- 26.1: Loom `net.fabricmc.fabric-loom`, официальные имена Mojang (yarn для 26.x не существует),
  Java 25 через toolchain, `./gradlew build` с `JAVA_HOME="C:/Program Files/Java/jdk-25.0.3"`.
- Долгие сборки — только на переднем плане с `dangerouslyDisableSandbox: true`, иначе падает
  на запись в `~/.gradle/.tmp`. Параллельные загрузки лечить `--max-workers=1`.
- `javap` не понимает MSYS-путь `/c/...` — передавать `C:/...`.
